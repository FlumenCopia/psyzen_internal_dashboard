AI Chat Service — Core Flow
class ChatService:
def process_message(self, session_id, user_message):
# 1. Load conversation history
history = ConversationHistory.get(session_id)
# 2. Risk detection BEFORE RAG (priority check)
risk = self.risk_detector.analyze(user_message, history)
if risk.level == 'CRITICAL':
return self.emergency_handler(session_id, risk)
# 3. RAG retrieval (Phase 3 — placeholder in MVP)
context = self.rag.retrieve(user_message) if self.rag_enabled else []
# 4. Generate response via local LLM
prompt = self.build_prompt(history, user_message, context, risk)
response = self.llm.generate(prompt) # Ollama API call
# 5. Safety filter response
safe_response = self.safety_filter.check(response)
# 6. Save + return
self.save_turn(session_id, user_message, safe_response, risk)
return safe_response

from langchain_community.vectorstores import Chroma
from langchain.embeddings import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
vectorstore = Chroma(persist_directory="./chroma_db",
embedding_function=embeddings)

def retrieve_context(query: str, k: int = 5) -> list:
docs = vectorstore.similarity_search(query, k=k)
return [d.page_content for d in docs]

🎯 The Strategic Challenge

Psyzen is selling a category that doesn't exist yet in the user's mind. Unlike Zomato (food delivery — understood) or Practo (book a doctor — understood), most potential users don't understand "AI mental health triage" or have never considered that a layered triage system for mental health exists. The entire first phase of DM is not about selling. It is about creating a mental model in the audience's mind so that when the platform launches, they immediately understand why it matters.

📌 Rule 1: Never publish clinical claims ("treats depression," "cures anxiety"). Always "supports," "guides," "helps understand." Rule 2: Never use crisis content as engagement bait. Rule 3: All mental health content reviewed against Instagram/Meta policy before scheduling.

Local LLM Implementation Guide
Privacy-First AI — Local LLM Options for Psyzen
Client requested local LLM (no cloud API) for DPDP privacy compliance. Patient mental health conversations must NOT leave your server. This guide covers all viable options, hardware requirements, and implementation steps.
🔒 DPDP Privacy Imperative: If you use OpenAI/Gemini APIs, every patient conversation passes through external servers. This is a potential DPDP Act violation for a healthcare platform handling sensitive mental health data. Local LLM eliminates this risk entirely. This is non-negotiable for Psyzen.
🦙 Ollama RECOMMENDED FOR PHASE 2
The easiest way to run local LLMs. Docker-like CLI — pull and run any model in one command. OpenAI-compatible API (your LangChain code works without changes). Best for getting started quickly in development. Supports LLaMA 3, Mistral, Qwen, Gemma and 100+ models.
Setup time30 minutes
Hardware (min)16GB RAM, 8GB VRAM GPU
ThroughputMedium (good for development)
APIOpenAI-compatible
CostFree + server cost
Setup Commands
# Install Ollama on Ubuntu server
curl -fsSL https://ollama.com/install.sh | sh

# Pull recommended models
ollama pull llama3.2:8b-instruct-q4_K_M # Best balance quality/speed
ollama pull mistral:7b-instruct # Good for multilingual
ollama pull qwen2.5:7b # Strong structured output

# Run with API exposed (for Django to call)
OLLAMA_HOST=0.0.0.0:11434 ollama serve

# Test it works
curl http://localhost:11434/api/generate \
-d '{"model":"llama3.2:8b-instruct-q4_K_M","prompt":"Hello"}'
LangChain Integration (Django)
from langchain_community.llms import Ollama
from langchain.callbacks.streaming_stdout import StreamingStdOutCallbackHandler

llm = Ollama(
model="llama3.2:8b-instruct-q4_K_M",
base_url="http://localhost:11434",
temperature=0.3, # Lower temp = more consistent responses
num_ctx=4096, # Context window
callbacks=[StreamingStdOutCallbackHandler()]
)
⚡ vLLM / OpenLLM RECOMMENDED FOR PHASE 3 PRODUCTION
8x throughput vs Ollama in benchmarks. Production-grade, supports batching, streaming, and multiple concurrent requests. OpenAI-compatible API. Ideal when multiple patients are using the platform simultaneously. More setup complexity than Ollama but dramatically better production performance.
Setup time2–4 hours
Hardware (min)24GB VRAM GPU (A10/RTX 4090)
Throughput8x vs Ollama
APIOpenAI-compatible
CostGPU server ₹30–80K/mo
